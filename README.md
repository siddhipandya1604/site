# Portfolio

Personal portfolio of Siddhi Pandya — AI/ML Engineer.

Built with React, React-Bootstrap and react-tsparticles.

## Run locally

```bash
npm install
npm start
```

Opens at http://localhost:3000

## Build

```bash
npm run build
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Publishes the production build to the `gh-pages` branch. The site is served
from the `homepage` URL configured in `package.json`.
